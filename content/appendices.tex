\section{\textit{AI.RTISANSHIP} technical documentation}

\textit{AI.RTISANSHIP} experiment, mentioned in Chapter 2, represented an attempt to capture and digitize traditional pottery techniques through computer vision and machine learning. The following technical documentation outlines its implementation, from data collection to the real-time prediction deployment.

\vspace{0.5cm}

The code for this project can be found opened under an MIT license on the following \href{https://github.com/jmuozan/ML_Sequence_Recognition}{GitHub} repository.

\subsection{Overview}

The system consisted of a machine learning system organized into seven main sections within a Jupyter notebook environment (\texttt{ML\_Sequence\_Recognition.ipynb}).

\vspace{0.5cm}

Technology stack used:
\begin{enumerate}
\item MediaPipe for holistic landmark detection (pose and hand tracking)
\item OpenCV for computer vision and video processing
\item TensorFlow/Keras for bidirectional LSTM neural network training
\item Pandas and NumPy for data processing and feature extraction
\end{enumerate}

\vspace{0.5cm}

This system developed captures 225-dimensional feature vectors from pose and hand landmarks using MediaPipe, processes sequences through LSTM networks, and provides real-time feedback about movement correctness sequences.

\subsection{Data collection}

\subsubsection{Library setup and MediaPipe configuration}

MediaPipe's holistic model was used to do a simultaneous pose and hand tracking through webcam live recording.

\subsubsection{Feature extraction system}

\begin{verbatim}
def extract_keypoints(results):
    # Extract pose landmarks (33 points x 3 coordinates = 99 features)
    pose = np.array([[res.x, res.y, res.z] for res in 
                     results.pose_landmarks.landmark]).flatten() \
           if results.pose_landmarks else np.zeros(33*3)
    
    # Extract left hand landmarks (21 points x 3 coordinates = 63 features)
    lh = np.array([[res.x, res.y, res.z] for res in 
                   results.left_hand_landmarks.landmark]).flatten() \
         if results.left_hand_landmarks else np.zeros(21*3)
    
    # Extract right hand landmarks (21 points x 3 coordinates = 63 features)
    rh = np.array([[res.x, res.y, res.z] for res in 
                   results.right_hand_landmarks.landmark]).flatten() \
         if results.right_hand_landmarks else np.zeros(21*3)
    
    return np.concatenate([pose, lh, rh])
\end{verbatim}

Extracted data points positions into numpy arrays for posterior processing.

\subsubsection{LSTM neural network architecture}

The classification system used a three-layer bidirectional LSTM architecture for temporal sequence recognition.

\begin{verbatim}
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import LSTM, Dense, Dropout, Bidirectional
from tensorflow.keras.regularizers import l2
from tensorflow.keras.optimizers import Adam

# Build bidirectional LSTM architecture
model = Sequential([
    # First bidirectional layer with return sequences
    Bidirectional(LSTM(64, return_sequences=True, activation='tanh'), 
                  input_shape=(sequence_length, 225)),
    Dropout(0.2),
    
    # Second bidirectional layer with L2 regularization
    Bidirectional(LSTM(128, return_sequences=True, activation='tanh', 
                       kernel_regularizer=l2(0.01))),
    Dropout(0.2),
    
    # Final bidirectional layer
    Bidirectional(LSTM(64, activation='tanh')),
    
    # Dense classification layers
    Dense(64, activation='relu'),
    Dense(32, activation='relu'),
    Dense(num_classes, activation='softmax')
])

# Compile model with Adam optimizer
optimizer = Adam(learning_rate=0.001)
model.compile(optimizer=optimizer, 
              loss='categorical_crossentropy', 
              metrics=['accuracy'])
\end{verbatim}

\subsection{Real-time prediction system}

\subsubsection{Live processing pipeline}

To test the results of the training a real-time detection system was created, integrating MediaPipe detection with the trained model inference:

def mediapipe_detection(image, model):
    # Process frame through MediaPipe pipeline
    image = cv2.cvtColor(image, cv2.COLOR_BGR2RGB)
    image.flags.writeable = False
    results = model.process(image)
    image.flags.writeable = True
    image = cv2.cvtColor(image, cv2.COLOR_RGB2BGR)
    return image, results

def draw_styled_landmarks(image, results, incorrect_movement):
    # Render landmarks with correctness-based color coding
    color = (0, 0, 255) if incorrect_movement else (0, 255, 0)  # Red/Green
    
    # Draw pose landmarks
    if results.pose_landmarks:
        mp_drawing.draw_landmarks(
            image, results.pose_landmarks, mp_pose.POSE_CONNECTIONS,
            mp_drawing.DrawingSpec(color=color, thickness=2),
            mp_drawing.DrawingSpec(color=color, thickness=2))

The system provided visual feedback through color-coded landmark rendering - green for correct movements, red for incorrect ones.

\subsubsection{Rolling buffer for temporal context}

\section{\textit{CR3ATED} Technical documentation}

The \textit{CR3ATED} web application was developed to test alternative interface approaches in order to preserve creative agency within digital fabrication workflows. This technical documentation will explain generally the implementation of the 3D revolution modeling webapp focusing on its main capabilities: 3D generation from drawings, image-based surface modification, and displacement mapping.

\vspace{0.5cm}

The complete source code is open-sourced under an MIT License at \href{https://github.com/jmuozan/CR3ATED}{GitHub}, and can the live website can be accessed \href{https://jmuozan.github.io/CR3ATED/}{here}.

\subsection{System overview}

Tech stack:
\begin{enumerate}
\item Three.js for 3D rendering and scene management
\item WebGL-accelerated graphics through Three.js WebGLRenderer
\item Custom Loop Subdivision implementation for mesh smoothing
\item HTML5 Canvas API for image processing and drawing interfaces
\end{enumerate}

The webapp supports STL import/export, image-based displacement mapping, interactive mesh subdivision, and real-time 3D manipulation through touch and mouse interfaces.

\subsection{Mesh management}

The application also provides STL file loading capabilities to allow users bring and modify their own models.

\begin{verbatim}
export function handleSTLUpload(params) {
    const file = params.event.target.files[0];
    if (file) {
        const reader = new FileReader();
        
        reader.onload = function (e) {
            const loader = new THREE.STLLoader();
            const geometry = loader.parse(e.target.result);

            if (params.mesh) {
                params.scene.remove(params.mesh);
                params.scene.remove(params.wireframe);
            }

            geometry.computeVertexNormals();
            
            // Store original positions for displacement operations
            geometry.originalPositions = geometry.attributes.position.array.slice();

            const newMesh = new THREE.Mesh(geometry, params.solidMaterial);
            const newWireframe = new THREE.Mesh(geometry.clone(), params.wireframeMaterial);
            newWireframe.visible = false;

            // Default vertical orientation
            newMesh.rotation.x = -Math.PI / 2;
            newWireframe.rotation.x = -Math.PI / 2;

            params.scene.add(newMesh);
            params.scene.add(newWireframe);
        };
        reader.readAsArrayBuffer(file);
    }
}
\end{verbatim}

This import process uses Three.js STLLoader to parse either binary or ASCII STL files. The system will automatically compute vertex normals for proper lighting and store vertex positions for posterior displacement operations.

\subsection{Image-based displacement mapping}

\subsubsection{UV coordinate generation}

UV coordinate genration is the responsable of creating the mapping between 2D texture space and 3D mesh surfaces for posterior displacement operations

\begin{verbatim}
export function generateUVs(geometry, displacementSettings) {
    const position = geometry.attributes.position;
    const box = new THREE.Box3().setFromBufferAttribute(position);
    const size = new THREE.Vector3();
    box.getSize(size);

    const uv = new THREE.BufferAttribute(new Float32Array(position.count * 2), 2);
    const positionArray = position.array;

    for (let i = 0; i < position.count; i++) {
        const x = positionArray[i * 3];
        const y = positionArray[i * 3 + 1];
        const z = positionArray[i * 3 + 2];
        
        // Project to XZ plane for UV mapping
        let uvX = (x - box.min.x) / size.x;
        let uvY = (z - box.min.z) / size.z;
        
        if (displacementSettings.flipUV) {
            uvX = 1 - uvX;
            uvY = 1 - uvY;
        }
        
        uv.setXY(i, uvX, uvY);
    }

    geometry.setAttribute('uv', uv);
    return uv;
}
\end{verbatim}

This UV generation process calculates the bounding box of the mesh geometry and projects 3D vertices onto the XZ plane, creating a planar mapping.

\subsubsection{Displacement calculation and application}

Displacement on the other hand implements real-time surface deformation based on image height data so mesh vertices can be moved according to the mapping previousely done based on the desired image by the user.

export function applyDisplacementMap(geometry, texture, scale, displacementSettings) {
    if (!texture || !geometry) return geometry;
    
    geometry.computeVertexNormals();

    const position = geometry.attributes.position;
    const normals = geometry.attributes.normal;
    const uv = generateUVs(geometry, displacementSettings);
    const dispMap = texture.image;

    if (!dispMap) return geometry;

    // Create canvas for image data extraction
    const canvas = document.createElement('canvas');
    canvas.width = dispMap.width;
    canvas.height = dispMap.height;
    const context = canvas.getContext('2d');
    context.drawImage(dispMap, 0, 0);
    const imageData = context.getImageData(0, 0, dispMap.width, dispMap.height);
    const data = imageData.data;

    // Process displacement per vertex
    const positionArray = position.array;
    
    for (let i = 0; i < position.count; i++) {
        // Sample displacement from image
        const ux = Math.floor(uv.getX(i) * dispMap.width);
        const uy = Math.floor(uv.getY(i) * dispMap.height);
        const pixelIndex = (uy * dispMap.width + ux) * 4;
        const displacement = (data[pixelIndex] / 255) * scale;
        
        // Apply displacement along vertex normal
        const normalX = normals.getX(i);
        const normalY = normals.getY(i);
        const normalZ = normals.getZ(i);
        
        position.setXYZ(
            i,
            positionArray[i * 3] + normalX * displacement,
            positionArray[i * 3 + 1] + normalY * displacement,
            positionArray[i * 3 + 2] + normalZ * displacement
        );
    }

    position.needsUpdate = true;
    geometry.computeVertexNormals();
    return geometry;
}
\end{verbatim}

\subsection{Usage guidelines and capabilities}

For optimal results with the drawing interface, users should draw "clear" and as "smooth" as possible profiles of their desired revolution surface. For effective displacement mapping, users should use high-contrast images where lighter areas represent raised surfaces and darker areas represent recessed areas, adding, if possible, higher levels of subdividion to the meshes, as that will define the amount of vertices tha move. 

\subsection{Technical limitations and considerations}

The implementation has several limitations, the displacement mapping depends on browser Canvas API support and may be computationally intensive for very large meshes. The drawing interface works best on touch devices but also supports mouse input for desktop users even though the web might not be properly responsive.

\section{\textit{AI Tools} Technical documentation}

\textit{AI Tools} plugin is an integration of artificial intelligence capabilities into parametric design workflows through Grasshopper. The documentation presented here will explain how thetwo components that represent the plugin use external AI services to generate 3D models from text prompts and analyze images to create detailed modeling instructions.

\vspace{0.5cm}

Source code is available and opened under MIT License at \href{https://github.com/jmuozan/AI_3D_Models_Grasshopper}{GitHub}, and the compiled plugin can be downloaded from \href{https://www.food4rhino.com/en/app/ai-tools}{Food4Rhino}.

\subsection{System architecture overview}

The plugin consists of two main components that integrate AI services into the software. The source code combines Python scripts for AI service integration with C\# for Grasshopper component management.

\vspace{0.5cm}

Tech stack:
\begin{enumerate}
\item ZOO's Text-to-CAD API for natural language to 3D model generation
\item OpenAI's GPT-4 Vision API for image analysis and prompt generation
\item Python 3
\item C\# .NET Framework 4.8 
\item RhinoCommon API for geometry processing and file handling
\end{enumerate}

\vspace{0.5cm}

Plugin supports STEP, STL, and OBJ file formats and real-time integration within the Grasshopper visual programming environment. STEP files selected as default due to their superior compatibility with CAD software and preservation of parametric information.

\subsection{Text to CAD component implementation}

Text to CAD component integrates with ZOO's Text-to-CAD API to generate 3D models from natural language descriptions. The component receives four input parameters: API key for ZOO authentication, directory path for temporary file storage, text prompt describing the desired 3D model and a boolean trigger to initiate generation. The outputs include the generated Brep geometry and the file path to the created STEP file.

\subsection{Usage guidelines and best practices}

For effective image analysis, users should use high quality, ensure objects are clearly visible, avoid cluttered backgrounds and focus on "manufacturable" objects.

private void CompileCode(string code, string outputPath)
{
    var syntaxTree = CSharpSyntaxTree.ParseText(code);
    
    // Gather references from loaded assemblies
    var assemblies = AppDomain.CurrentDomain.GetAssemblies()
        .Where(a => !a.IsDynamic && !string.IsNullOrEmpty(a.Location) 
               && File.Exists(a.Location))
        .Select(a => a.Location)
        .Distinct();
        
    var refs = assemblies.Select(path => 
        MetadataReference.CreateFromFile(path)).ToList();
    
    // Create compilation
    var compilation = CSharpCompilation.Create(
        Path.GetFileNameWithoutExtension(outputPath),
        new[] { syntaxTree },
        refs,
        new CSharpCompilationOptions(OutputKind.DynamicallyLinkedLibrary));
        
    var result = compilation.Emit(outputPath);
    
    if (!result.Success)
    {
        var failures = result.Diagnostics.Where(d => 
            d.Severity == DiagnosticSeverity.Error);
        var sb = new StringBuilder("Compilation failed:");
        foreach (var diag in failures)
            sb.AppendLine(diag.ToString());
        throw new Exception(sb.ToString());
    }
}

private static bool TryFitCircleRobust(List<Point3d> pts, double tol,
    out Point3d center, out double radius, out bool clockwise)
{
    // Least-squares circle fitting implementation
    int n = pts.Count;
    if (n < 3) return false;
    
    double sumX = 0, sumY = 0, sumX2 = 0, sumY2 = 0, sumXY = 0;
    double sumX3 = 0, sumY3 = 0, sumX2Y = 0, sumXY2 = 0;
    
    foreach (var pt in pts)
    {
        double x = pt.X, y = pt.Y;
        sumX += x; sumY += y;
        sumX2 += x * x; sumY2 += y * y; sumXY += x * y;
        sumX3 += x * x * x; sumY3 += y * y * y;
        sumX2Y += x * x * y; sumXY2 += x * y * y;
    }
    
    // Solve for circle center using determinant method
    double a = n * sumXY - sumX * sumY;
    double b = n * sumX2 - sumX * sumX;
    double c = n * sumY2 - sumY * sumY;
    double det = a * a - b * c;
    
    if (Math.Abs(det) < 1e-12) return false;
    // Calculate center and validate geometry
}

private void StartHandTracking()
{
    try
    {
        var scriptPath = Path.Combine(Directory.GetCurrentDirectory(), 
            "scripts", "meshedit", "hands.py");
        var startInfo = new ProcessStartInfo
        {
            FileName = "python3",
            Arguments = $"-E \"{scriptPath}\" --headless",
            RedirectStandardOutput = true,
            RedirectStandardError = true,
            UseShellExecute = false,
            CreateNoWindow = true
        };
        
        _handProcess = Process.Start(startInfo);
        _handTrackingThread = new Thread(() =>
        {
            bool pinched = false;
            string line;
            while (_handProcess != null && !_handProcess.HasExited && 
                   (line = _handProcess.StandardOutput.ReadLine()) != null)
            {
                var parts = line.Split(' ');
                if (parts.Length < 5) continue;
                
                // Parse hand landmark data and detect pinch gestures
                if (float.TryParse(parts[0], out var tx) && 
                    float.TryParse(parts[1], out var ty) &&
                    float.TryParse(parts[4], out var dist))
                {
                    Application.Instance.Invoke(() =>
                    {
                        // Convert normalized coordinates to screen space
                        var mx = (1 - (tx + ix) * 0.5f) * ClientSize.Width;
                        var my = ((ty + iy) * 0.5f) * ClientSize.Height;
                        var loc = new PointF(mx, my);
                        
                        // Detect pinch gesture and trigger mesh manipulation
                        if (!pinched && dist < 0.08f)
                        {
                            pinched = true;
                            if (_mode == Mode.Edit && _selectedVertices.Count > 0)
                            {
                                _isGroupDragging = true;

                                    .Select(i => _vertices[i]).ToList();

                                _dragAnchorWorld = Unproject(loc, _dragRefZ);
                            }
                        }
                    });
